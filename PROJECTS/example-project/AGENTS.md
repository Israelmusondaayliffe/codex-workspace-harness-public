# Project AGENTS.md: Example Project

This contract overlays the global and workspace contracts for work inside this project.

## Purpose

Demonstrate the minimum structure for a routed, verifiable project.

## Inputs

Read `references/workflow.md` before changing project files. Place temporary briefs in a local `inputs/` folder and ignore that folder if the briefs contain private data.

## Outputs

Write finished artifacts to `OUTPUTS/YYYY-MM-DD/example-project_[type]_v1.ext`.

## Workflow

1. Restate the requested outcome.
2. Read the project reference.
3. Define the expected artifact and verification check.
4. Produce the artifact in the dated output folder.
5. Run the check and report the exact output path.

## Success criteria

- The artifact answers the brief.
- The project contract and reference were followed.
- The output path and version are correct.
- Verification evidence is reported.
